# วิธีติดตั้ง ProTrack 4.0 บน Cloudflare พร้อมฐานข้อมูล D1

ชุดนี้ทำให้ข้อมูลโครงการ งบประมาณคงเหลือ ผู้รับผิดชอบ แบบรายงาน และลิงก์ไฟล์รายงานเป็นข้อมูลส่วนกลาง เปิดจากอุปกรณ์ใดก็ได้โดยใช้รหัสผู้ดูแลเดียวกัน

## สิ่งที่ต้องใช้

- บัญชี GitHub ที่มีคลังไฟล์โครงการ
- บัญชี Cloudflare
- รหัสผู้ดูแลอย่างน้อย 6 ตัวอักษร ควรเป็นรหัสที่คาดเดายาก

## 1. นำไฟล์ขึ้น GitHub

แตกไฟล์ ZIP แล้วนำรายการต่อไปนี้วางไว้ที่รากของคลัง GitHub

- โฟลเดอร์ `public`
- โฟลเดอร์ `functions`
- ไฟล์ `schema.sql`
- ไฟล์ `README-Cloudflare-D1.md`

ห้ามอัปโหลดเฉพาะไฟล์ ZIP เข้า GitHub เพราะ Cloudflare ต้องเห็นโฟลเดอร์ `functions` เพื่อสร้าง API

## 2. สร้างฐานข้อมูล D1

1. เข้า Cloudflare Dashboard
2. เลือก Workers & Pages
3. เลือก D1 SQL Database
4. กด Create database
5. ตั้งชื่อ `protrack-db`

ไม่จำเป็นต้องสร้างตารางเอง เพราะระบบจะสร้างตารางที่ต้องใช้เมื่อเชื่อมต่อครั้งแรก แต่สามารถใช้ไฟล์ `schema.sql` ในหน้า Console เพื่อตรวจสอบหรือสร้างตารางล่วงหน้าได้

## 3. สร้าง Cloudflare Pages จาก GitHub

1. ไปที่ Workers & Pages แล้วเลือก Create application
2. เลือก Pages และ Connect to Git
3. เลือกคลัง GitHub ที่มีไฟล์ ProTrack
4. Framework preset เลือก None
5. Build command เว้นว่าง
6. Build output directory กรอก `public`
7. กด Save and Deploy

ชุดนี้มี Pages Function จึงต้องเผยแพร่ผ่าน GitHub หรือ Wrangler ไม่สามารถใช้การลาก ZIP เข้า Direct Upload ในหน้า Cloudflare ได้

## 4. ผูกฐานข้อมูลกับเว็บไซต์

1. เปิดโครงการ Pages ที่สร้างไว้
2. ไปที่ Settings > Bindings
3. กด Add binding และเลือก D1 database
4. Variable name ต้องกรอก `DB` ตัวพิมพ์ใหญ่
5. เลือกฐานข้อมูล `protrack-db`
6. บันทึกแล้วสั่ง Redeploy

## 5. ตั้งรหัสผู้ดูแล

1. ไปที่ Settings > Variables and Secrets
2. เพิ่มตัวแปรชื่อ `PROTRACK_ADMIN_PIN`
3. กรอกรหัสที่ต้องการใช้งานจริง และเลือกชนิด Secret
4. บันทึกแล้วสั่ง Redeploy อีกครั้ง

อย่าเขียนรหัสนี้ลงในไฟล์ HTML หรือไฟล์ GitHub

## 6. เชื่อมต่อใน ProTrack

1. เปิดเว็บไซต์ Cloudflare ที่ได้
2. ไปที่เมนูตั้งค่า
3. ในหัวข้อฐานข้อมูลส่วนกลาง Cloudflare D1 กรอกรหัสเดียวกับ `PROTRACK_ADMIN_PIN`
4. กดบันทึกรหัสและเชื่อมต่อ
5. ครั้งแรกระบบจะส่งทะเบียนโครงการปี 2569 ขึ้นฐานข้อมูลให้อัตโนมัติ

เมื่อเปิดจากเครื่องอื่น ให้เปิดเว็บไซต์เดิม กรอกรหัสผู้ดูแลเดียวกัน แล้วกดดึงข้อมูลล่าสุด

## ข้อมูลที่ซิงค์

- ทะเบียนโครงการและกิจกรรม
- งบประมาณที่ได้รับ ใช้ไป และคงเหลือ
- ผู้รับผิดชอบ
- ประวัติการเบิกจ่าย
- ข้อมูลแบบรายงานกิจกรรม
- สถานะกิจกรรมและสถานะรายงาน
- ลิงก์ไฟล์รายงานใน Google Drive

ไฟล์ PDF, DOC และ DOCX ยังคงเก็บใน Google Drive ส่วน D1 เก็บข้อมูลและลิงก์อ้างอิง

## การป้องกันข้อมูล

- ผู้ใช้งานต้องมีรหัสผู้ดูแลจึงจะอ่านหรือแก้ไขข้อมูลส่วนกลางได้
- ระบบบันทึกในอุปกรณ์ก่อน หากอินเทอร์เน็ตขัดข้องจะขึ้นข้อความว่ายังซิงค์ไม่สำเร็จ
- เมื่ออินเทอร์เน็ตกลับมา ให้กดดึงข้อมูลล่าสุดหรือบันทึกข้อมูลอีกครั้ง
- ควรกดสำรองรายงานเป็นระยะ โดยใช้ปุ่มสำรองรายงานในหน้า ProTrack
